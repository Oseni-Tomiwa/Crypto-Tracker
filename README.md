# 📊 Crypto Tracker

A modern cryptocurrency tracking web app built with React. It provides real-time data on various cryptocurrencies, allowing users to search, explore, and monitor market trends through a clean and responsive interface.

## 🚀 Features
- 📈 Real-time cryptocurrency price tracking  
- 🔍 Search and filter coins  
- 📊 View key data (price, market cap, 24h change)  
- 📱 Responsive design (mobile & desktop)  
- ⚡ Fast and optimized UI  

## 🛠️ Tech Stack
- React  
- JavaScript (ES6+)  
- CSS / Tailwind (optional)  
- Public Crypto API (e.g., CoinGecko)
